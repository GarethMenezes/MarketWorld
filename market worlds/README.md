# Market Worlds — legacy demo

This is the old version. Further development happened on [sota](https://github.com/GarethMenezes/MarketWorld/tree/sota), which was merged into [main](https://github.com/GarethMenezes/MarketWorld/tree/main).

To try this demo, install Git and Python 3, then run:

```sh
git clone --branch gareth https://github.com/GarethMenezes/MarketWorld.git
cd "MarketWorld/market worlds"
python3 -m http.server 4173 --directory dist
```

Open [localhost:4173](http://localhost:4173) in a modern browser with WebGL 2 support. This runs on your own computer; keep the terminal open while using it.

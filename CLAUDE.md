# Market Worlds — project guide for Claude Code

DurHack 2026 project for the Marshall Wace "New Worlds" challenge: *"Build something that opens a door to the unexplored — new data, ideas or something novel no one has seen before."*

Market Worlds turns ~20 years of real stock market data into a 3D planet you can explore. Sectors are continents, companies are mountains, market fear is the weather, crashes are earthquakes, and when correlation rises the continents drift together into one supercontinent.

**Deadline:** Sunday morning 2026-11-15. Prefer simple, working, demo-ready code over clever code.

## 1. The idea (why every visual exists)

Every visual must map to a real number. No data-free effects except pure atmosphere (stars, sun, camera spin).

| Market data | World feature | Field in world.json |
|---|---|---|
| Sector | Continent with its own colour and organic terrain | `sectors[]` |
| Company | Rocky mountain on its continent | `stocks[]` |
| Growth since 2007 | Mountain height (log scale) | `stocks[].growth` |
| Weekly return | Mountain colour red/yellow/green; bigger moves glow more | `stocks[].ret` |
| Volatility | (available: per-continent storms if time) | `stocks[].vol`, `sectors[].vol` |
| Market fear (VIX) | Sky, atmosphere blue→red, cloud cover/darkness, lightning | `market.vix` |
| Crash week | Earthquake when average weekly return < -7% | `market.ret` |
| Average sector correlation (30-day) | Sea level falls; salt-flat shelves exposed around every coast | `market.avgCorr` |

Key insight for judges: in calm markets sectors move independently (continents spread out); in a crisis everything falls together (correlation → 1, the sea drains and the continents join into one landmass). Diversification fails exactly when you need it.

Not a trading tool — the UI says "For exploration and education — not financial advice".

## 3. Data pipeline and JSON contract

30 large US stocks (5 per sector) + ^VIX from 2007. Daily adjusted closes → returns → 20-day annualised vol. Sector return = mean of its stocks. avgCorr = mean pairwise correlation of sector daily returns over a rolling **30-day** window (60 days lagged the 2008 crash too much). Weekly frames W-FRI. Growth = price / first valid price. Days when only VIX traded are dropped.

```json
{
  "dates":   ["2007-01-05", "..."],
  "sectors": [{ "name": "Technology", "tickers": ["AAPL"], "ret": [], "vol": [] }],
  "stocks":  [{ "ticker": "AAPL", "sector": "Technology", "growth": [], "ret": [], "vol": [], "relVolume": [] }],
  "market":  { "ret": [], "vix": [], "avgCorr": [] }
}
```
Every array has one value per date; `null` = no data. Do not change without updating both sides.

Known limitations (say honestly): height uses price growth, not market cap; today's large companies → survivorship bias.

Real-data reference points: VIX peaks 2008-10-24 (79), 2020-03 (~66). avgCorr: 2017 ≈ 0.13, 2008-10-10 = 0.77, 2011-08 ≈ 0.9, 2020-03-20 = 0.86. Worst weeks: 2008-10-10 (-19.9%), 2020-03-20 (-15%), 2020-02-28, 2020-03-13, 2025-04-04.

## 4. Stack and rules

- Frontend: plain JS ES modules + Three.js 0.170 + Vite 5 (Node 18 compatible). No React/TS. Add-ons from `three/addons/...`.
- Data: Python 3.10+, pandas, numpy, yfinance.
- Backend: FastAPI + uvicorn in `server/`. LLM key ONLY in a backend env var.
- 3D world must work offline; AI text falls back gracefully.
- ~60 fps on integrated graphics; no per-frame allocations in `animate()`.
- AI text labelled "Generated by AI", only uses numbers we give it.

Tunables live in `CONFIG` at the top of main.js (height, colorSensitivity 20, drift corrLow 0.25 / corrHigh 0.82, storm vixCalm 13 / vixRange 45, clouds, lightningVix 40, quakeRet -0.07, weekMs 120).

## 8. Notes from building it

- In the browser console (dev only) `window.mw` exposes scene, camera, controls, continents, state, CONFIG.
- Performance measured on Intel Arc iGPU: 8.6 ms/frame at pixel ratio 1.5. Low fps seen through browser automation is rAF throttling, not GPU cost.
- On laptops with a dGPU, set Chrome to "High performance" in Windows Graphics settings.
- Lehman week (2008-09-19): Financials' weekly return is only -0.3% (Friday rescue rally) — the story is VIX + correlation rising, say so in the demo.

## 9. Sea level model (replaces continental drift)

- Continents are FIXED (octahedron `PLATE_DIRS`) with organic shapes (per-continent size, stretch,
  rotation, domain-warped coasts, a few offshore islands: `continentShape` in the shader). No bridges.
- `uSeaLevel` (shader) from avgCorr: normal at ≤ 0.3, lowest at ≥ 0.85 (`CONFIG.sea`).
- `market.pairCorr` (60-day, 15 pairs) is in world.json but currently unused by the frontend.
- Planet look: dark night side, polar ice, ocean glint, limb haze, thin rim, full-res rendering (dpr 2).
- Exposed seabed = wet sand → salt flats; foam at the shore; faint ring at the normal shoreline.

## 10. Markets (one planet each)

- `build_world.py --market us|uk|asia|all [--cached]`; `MARKETS` table holds tickers, names and the fear source.
  US → world.json / stress.json (unchanged names); others → world-<id>.json / stress-<id>.json;
  public/markets.json lists them. UK/Asia fear = 20-day realised volatility (no free fear index).
- Frontend: `?market=` picks the planet; `PLANET_LOOKS` in main.js gives each its seed, layout spin,
  ocean and atmosphere colours. The tour (US events) only shows on the US planet.
- Backend: /api/explain and /api/ask take `market` (default "us").
